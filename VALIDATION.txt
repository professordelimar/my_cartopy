Runtime note
------------
Cartopy itself was not available in the artifact-build container, so the committed previews were rendered with equivalent PROJ projection definitions and Basemap/Natural-Earth-style geometry; selected shaded-relief previews use Basemap's packaged ETOPO raster. The standalone scripts in scripts/ are Cartopy-native and are the canonical implementations for this repository.

For strict Cartopy reproduction, create the conda-forge environment from environment.yml and run:

    python run_all.py

This regenerates images/ directly with Cartopy and Natural Earth 10m features at 400 dpi.
